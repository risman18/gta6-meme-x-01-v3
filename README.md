A GTA 6 meme drawn from scratch with Python + Pillow: a Leonida State Prison release form — every GTA fan just served 13 years waiting for GTA VI (GTA V came out 17 Sep 2013, GTA VI out 19 Nov 2026), stamped TIME SERVED, with make.fun's ghost mascot as a fellow inmate in an orange jumpsuit holding its magenta star coin. GTA VI IS OUT NOW.

## Run it

```sh
python3 draw_meme.py
```

This regenerates `meme.png` (1024×1024). It needs Python 3 with Pillow installed; no network access is needed. The entry program `main.ts` copies `POST.json` to `/output` — the post itself is the entry, and the parent posts the meme on X and fills in `POST.json` with the post's address.
